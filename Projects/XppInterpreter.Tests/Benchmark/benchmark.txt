// Benchmark snippets: each one runs compiled by the real X++ compiler and through the interpreter, on an AOS.
// Scripts\RunBenchmark.ps1 runs them, see Docs\Development.md.
//
// Format:   ### name           b + two digits + a name; the digits group the cases, so a filter like "b4" runs one group
//           source lines       the body of a static method that returns a str, used as it is for both runs
//
// Both runs have to return the same value: the report marks a case where they differ.
// Keep a case to one construct inside a loop, so its time minus the time of b01_emptyLoop is the cost of that construct.
// The data cases read USMF demo data (CustTable, InventTrans, SalesLine): open the class with &cmp=USMF.
// The model needs a reference to ContactPerson for the CustTable cases.
//
// b20 to b22 call a class of the model the benchmark is in. The interpreter belongs to another publisher, and the kernel
// opens a publisher scope whenever a method of another publisher is entered: about 20 microseconds for each call, which
// compiled X++ pays too when it calls a model of another publisher. Calls to Microsoft code (b23, b24) don't pay it.

### b49_typicalScript
int n;
real total;
SalesLine sl;
Map qtyPerItem = new Map(Types::String, Types::Real);
while select sl
{
    if (sl.SalesStatus == SalesStatus::Invoiced && sl.SalesQty > 0)
    {
        total += sl.LineAmount;
        if (qtyPerItem.exists(sl.ItemId))
        {
            qtyPerItem.insert(sl.ItemId, qtyPerItem.lookup(sl.ItemId) + sl.SalesQty);
        }
        else
        {
            qtyPerItem.insert(sl.ItemId, sl.SalesQty);
        }
        n++;
    }
}
return strFmt('%1 %2', n, qtyPerItem.elements());
